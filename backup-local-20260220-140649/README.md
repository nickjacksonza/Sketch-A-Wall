# Sketch-a-Wall

## Overview
Sketch-a-Wall is a React application that allows users to create and manipulate wall layouts on a canvas. Users can add walls, adjust their lengths and angles, and export their designs.

## Features
- Add walls with specified lengths and angles.
- Drag and position walls on a grid.
- Delete selected walls.
- Upload a background image for reference.
- Export the wall layout as a JSON file.

## Getting Started

### Prerequisites
- Node.js (version 14 or higher)
- npm (Node package manager)

### Installation
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/sketch-a-wall.git
   ```
2. Navigate to the project directory:
   ```
   cd sketch-a-wall
   ```
3. Install the dependencies:
   ```
   npm install
   ```

### Running the Application
To start the development server, run:
```
npm run dev
```
Open your browser and navigate to `http://localhost:3000` to view the application.

### Building for Production
To create a production build, run:
```
npm run build
```

## Usage
- Use the toolbar to add walls, delete selected walls, and toggle the grid.
- Click on walls to select and edit their properties.
- Drag walls to reposition them, snapping to grid intersections.
- Upload a background image for reference and adjust its opacity.
- Export your layout as a JSON file for future use.
